### Added

- **Apache Tomcat outside a package manager is inventoried and matched against its vulnerabilities.** The Tomcat the official `tomcat` container images unpack into `/usr/local/tomcat`, and tarballs in `/opt/tomcat` or `/opt/apache-tomcat-*`, were not listed at all: only the web applications deployed in them were read. The agent and image scans now report each one as the runtime `tomcat`, with the release read from `lib/catalina.jar` (nothing is run), so its end of life is checked, and match it against Tomcat's NVD records through the vendor build catalogue, as nginx in 0.20.28. A vendor's build such as Red Hat JBoss Web Server is reported but not matched against Apache's records. The action plan says "Update Apache Tomcat 10.1 to 10.1.58". See [Tomcat outside a package manager](docs/compatibility.md#tomcat-outside-a-package-manager).
