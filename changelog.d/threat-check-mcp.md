### Added

- **Ask Stackurity and AI assistants answer "are we affected by ARTEX?".** The new MCP tool `threat_check` takes a named attacker tool or campaign (ARTEX first) and returns what it is and its sources, whether it was found on an asset, the internet-facing (or possibly internet-facing) assets with open known-exploited or critical findings, which connections its checks need and which are missing (with the Help page for each), and a verdict: `found`, `exposed`, `not_checked` or `covered`. On a server without the attack-tool checks the verdict is `not_checked` and says to upgrade. The new tool `list_risky_settings` lists [risky settings](docs/config-checks.md) (agent hooks, SSH access, GitHub Actions and attacker tools), which had no MCP tool before. Both are read-only and offered to Ask Stackurity. See [AI assistants](docs/ai-assistants.md).
