### Added

- **Puppet's own puppet-agent packages are matched against NVD.** A `puppet-agent` installed from Puppet's repository (`8.10.0-1jammy`, `8.10.0-1bookworm`, `8.10.0-1.el9`) was a vendor build no source read, so it stayed `unsupported`. It is now in the vendor build catalogue and matched by its release against NVD's records for `puppet:puppet`, which describe the code Puppet Server runs. This covers CVE-2026-115731 (report deserialisation code execution on Puppet Server, in CISA's Known Exploited Vulnerabilities catalogue since 17 November 2026; 8.0.0 to 8.22.1 and 9.0.0 to 9.1.2). Puppet's public repository ends at 8.10.0, so the update advice says to move to Puppet Core or OpenVox. Puppet's release lines also get their end of life from endoflife.date. Ubuntu's and Debian's own `puppet-agent` builds keep their distribution's advisories. The `puppetserver` package's own version, Puppet Enterprise and OpenVox are not read yet. See [compatibility.md](docs/compatibility.md#vendor-builds).
