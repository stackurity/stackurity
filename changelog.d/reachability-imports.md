### Added

- **Not imported, from the source:** repository scans and `stackurity scan` read first-party Go, JavaScript/TypeScript, PHP and Python files (as data, within the scan's limits) and mark each lockfile package reachable (with the file that imports it), not imported, or not assessed. Not imported is claimed only for a direct npm or Composer dependency that no source, template, script or configuration names, from a lockfile that records the dependency graph (`package-lock.json` version 2 or 3, `composer.lock`) in which no other package depends on it. Transitive dependencies, Go modules, Python packages, computed `require()` calls, minified bundles and anything named by string, by its `node_modules/` path or by `npx` stay not assessed. The coverage entry `reachability` says what was read. See [docs/reachability.md](docs/reachability.md#repositories-and-stackurity-scan-not-imported).
