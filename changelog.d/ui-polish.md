### Changed

- **Tables can be more compact or more spacious.** Lists have a Rows control (Comfortable, Default, Compact) above the table, remembered in your browser. Default looks as before.
- **The filters you have on show as chips.** On Assets, Components, Incidents and the Audit log, each filter on appears above the table with × to remove it, plus Clear all.
- **Lists show their shape while loading.** Tables and approval lists show grey placeholder rows instead of a "Loading…" line, so the page no longer jumps. The shimmer stops if your system asks for less motion.
- **Long asset names and package identifiers keep their ends visible.** A name too long for its column is cut in the middle, so the version stays in view; hover or tab to it to see it whole, and use the copy button beside it.
- **Red is kept for what is urgent.** A finding's New state is amber, not red. Delete and Disconnect buttons in settings tables are red links, like the others, rather than solid red buttons. Solid red delete buttons in the dark theme are readable (their text was below the contrast minimum).
- **Empty lists say what to do next.** With filters on, an empty Assets, Components, Incidents or Audit list offers Clear filters; with nothing yet, Assets offers Add server and Components links to Assets. An empty Ignore rules list links to the issues.
