### Added

- **`pkg/engine`: image archives and Windows hosts.** `engine.ImageArchive` and `engine.ImageArchiveFile` inventory a `docker save` or OCI image-layout archive (optionally gzip-compressed) with no Docker engine, using the same hardened extraction and collectors as the agent's `--docker`: the image's tags, platform and working directory come from the archive, a multi-platform OCI index is read for the asked architecture, and an image over the size limit (2 GiB by default, `MaxImageBytes`) is reported as skipped coverage rather than as an empty image. `engine.WindowsHost` reads a Windows machine's build and installed programs as the agent's Windows collector does (same collector, machine GUID identifier and evidence), and `engine.HostSoftware` now does so on Windows instead of returning nothing. These are additions; no existing function changed. The agent is unchanged.
